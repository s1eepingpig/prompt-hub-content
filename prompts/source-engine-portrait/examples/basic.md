# Example

**Inputs:**
- `{{reference_image}}` — a portrait of a young man.
- `{{scene}}` — eating with a friend in a university cafeteria, a pretty woman nearby.

**Expected result:** a vertical GoldSrc-style screenshot — blocky shadows, blurry pixel textures, angular low-poly faces — in which a viewer still recognizes the same person, standing among cafeteria tables in third person. No HUD, no captions, no realistic skin detail.

**Anti-pattern:** a clean modern 3D render or an anime illustration, or any output where the face no longer matches the reference.
