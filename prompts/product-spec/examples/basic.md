# Example

**Idea:** "Add favorites to the prompt site."

**Output (excerpt):**

```markdown
## Problem
Visitors find a useful prompt, leave, and cannot find it again without
re-searching. There is no way to keep a short list.

## Goal
Increase repeat visits from users who save at least one item by 20%.

## Non-goals
- Accounts or profiles.
- Sharing or exporting the list.
- Server-side sync.

## User stories
- As a visitor, I want to star an item so I can find it later.
- As a visitor, I want my stars to survive a reload without logging in.

## Open questions
- Assumption: local storage is acceptable for MVP.
- Do we need to cap list size?
```
