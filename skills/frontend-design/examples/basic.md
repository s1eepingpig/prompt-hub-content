# Example — a landing page that looks generated

**Input:** "Make me a landing page for a task app."

**Weak output (defaults):** white background, Inter, a purple→indigo gradient hero, three feature cards in a row, a generic icon set.

**Strong output (committed aesthetic):**

- **Type:** a high-contrast display serif for the headline (e.g. Fraunces) against a neutral grotesque for body.
- **Palette:** warm paper `#F4EFE6` base, ink `#1A1712` text, one saturated accent `#D6482B` used only on the primary CTA.
- **Layout:** asymmetric — an oversized headline in the left third, a live product excerpt on the right, generous negative space.
- **Motion:** a single staggered reveal on load: headline, then excerpt, then CTA, each with an incremental `animation-delay`.
- **Background:** subtle paper-grain noise plus a soft vignette; no gradient.

**Why it lands:** one coherent idea (warm analogue tool) drives every choice, and nothing matches the default AI palette or font stack.
